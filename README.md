# Remote Job Dashboard

A Flask-based web application that fetches live remote jobs using a real jobs API.

## Features

- Search remote jobs
- Live API integration
- Company logos
- Salary information
- Job type tags
- Posting dates
- Direct apply links

## Tech Stack

- Python
- Flask
- HTML
- CSS
- Requests API

## Run Locally

```bash
pip install flask requests
python app.py
